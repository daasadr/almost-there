# Hudba

Sem patří soubory `.mp3`, na které odkazuje `src/content/music.ts`.

Pozor na jednu věc, která se nedá vzít zpět: **co sem přijde, zůstane
navždy v historii gitu.** I kdyby se soubory později přesunuly jinam,
v historii zůstanou a každý build je bude kopírovat.

Hranice je kolem **padesáti megabajtů, tedy zhruba patnáct skladeb**.
Až se k ní seznam přiblíží, přesunou se do složky na serveru mimo
repozitář — a získá se tím navíc to, že přidání skladby přestane
znamenat nasazení.
